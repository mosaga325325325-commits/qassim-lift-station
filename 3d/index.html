الأساس التصميمي المبدئي والمواصفات

محطة رفع نهائية لمجمع الطالبات ببريدة (11,960 طالبة + طاقم الكليات — 60Hz)

التشغيل: 2 عاملة بحد أقصى + 1 احتياطية بتناوب متوازن

1. اختيارات المضخات والمواصفات (Cutter / Vortex)

  • • نقطة الاختيار: 8.0 ل/ث (28.8 م³/س) لكل مضخة عند TDH = 14.5 م تشغيلي (مع هامش طرح/أمان حتى 18.0 م)، قدرة 5.5 ك.و (7.5 حصان)، 1750 دورة/د (380V / 60Hz)، فتحة صلب ≥ 65 ملم.
  • • البدائل المكافئة المقترحة: Flygt N-Series أو Grundfos SEV / SE1 أو Wilo Rexa PRO (عزل IP68 / Class F، مع اعتماد منحنى المصنع عند 60Hz قبل التوريد).
  • • شرط الذروة (55 م³/س): تشغيل مضختين بالتوازي يحقق ~57.8 م³/س على خط Ø140، ويلزم مطابقة منحنى المصنع لتحقيق ≥ 7.64 ل/ث لكل مضخة.

2. المواسير وغرفتا المحابس (PE100 SDR17)

  • • خط الدخول القائم (P-75): Ø 400 ملم (40 م بعد MH-75، IL 590.328 / عمق -5.732 م، سعة قطاعية ≈ 5.0 م³) — يلزم تأكيده مساحياً قبل الحفر.
  • • غرفة محابس البيارة: 3 محابس عدم رجوع + 3 محابس عزل DN100 + مجمع DN150 + عداد تدفق مغناطيسي FT.
  • • خط الطرد المدفون (50 م): Ø 140 ملم PE100 SDR17 PN10 (سماكة 8.3 مم ← قطر داخلي 123.4 مم).
  • • غرفة التوزيع والمخارج: توزيع 2 × DN100 للخزانين + خط وايتات DN100 (Kamlock 4") + خط معالجة مستقبلية مغلق حالياً.

3. البيارة والتراكم وخطة الوايتات (32 م³)

  • • البيارة الرطبة (Ø 3.0 م × 7.50 م): حجم تشغيل 4.24 م³ (-6.30 إلى -6.90 م) وإيقاف متدرج للمساندة عند -6.60 م. الفارق فوق الإنذار (-5.80 م) حتى قاع الماسورة 6.8 سم (0.48 م³ ≈ 31 ث عند 55 م³/س).
  • • التراكم والتعافي: عند تجاوز سعة خط P-75 (5.0 م³) ينطلق إنذار خطر فيضان MH-75، ويعود المخزون المتراكم للضخ تلقائياً فور تعافي المضخات.
  • • الوايتات: لتفريغ 200–245 م³/يوم بوايت 32 م³ يلزم 7–8 رحلات مكتملة/يوم، ويُحسب مؤشر «آخر موعد آمن» وفق السعة الحرة الفعلية وحمولة الوايت المتبقية فقط.
